# AGENTS

This repository is a public collection of Agent Skills.

- Put each skill in `skills/<skill-name>/`
- Required file: `SKILL.md` with YAML frontmatter `name` and `description`
- `name` must be lowercase letters, numbers, and hyphens only
- Follow https://agentskills.io/specification
- Run skill tests under the gitignored repo-root `test/` directory (working directory, fixtures, and clone-and-run)
